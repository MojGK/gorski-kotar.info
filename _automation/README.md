# Automatizacija vijesti

Probni način provjerava RSS izvore i duplikate. AI nacrti zahtijevaju Actions tajnu `OPENAI_API_KEY`.

Lokalni testovi: `python3 -B -m unittest discover -s _automation -v`.

Nakon pregleda probnog izvještaja, redovno objavljivanje uključuje Actions varijabla `GK_AUTO_PUBLISH=true`.
